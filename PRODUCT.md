# Product

## Register

product

## Users

Private investors, students, and presenters who need to build a portfolio from tickers or ETFs, inspect risk and return metrics, compare allocations, and explain the result to someone else.

## Product Purpose

The app helps users enter a small portfolio, analyze historical performance and risk, compare the current allocation with optimized alternatives, and export or present the result. It is a compact one-screen finance tool, not a general dashboard or marketing site.

## Brand Personality

Pragmatic, precise, trustworthy.

The tone should feel like a serious analytical instrument: clear enough for first-time users, compact enough for experienced users, and calm enough for presentations.

## Anti-references

- Generic SaaS dashboards with empty hero sections
- Overdesigned AI chrome, excessive glow, or decorative clutter
- Unclear button labels that hide the next action
- Interfaces that force scrolling on desktop for core tasks

## Design Principles

- Keep the portfolio builder, analysis, and AI guidance understandable at a glance.
- Make the next action obvious before the user clicks it.
- Preserve the one-screen desktop layout while keeping mobile workable.
- Prefer clarity and feedback over visual noise.
- Keep existing data and analysis features intact while improving usability.

## Accessibility & Inclusion

Target WCAG-conscious interaction, with keyboard support, readable contrast, and sensible focus states. Reduce motion where possible and keep German labels direct and unambiguous.
